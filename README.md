A 3D paper-craft pop-up book that sums up the world news of **Thursday 19
November 2026** in a single image. Opening the book opens the whole day:

- **SUMMIT** — the first three-way Trump–Xi–Putin summit in Shenzhen
- **LAW** — the ICJ ruling on the Rohingya genocide case
- **COP31** — the climate talks in Antalya, Turkey
- **BRIDGE** — Ukraine's strike on the Crimea Bridge
- **OIL** — the Hormuz energy crisis after the Gulf strikes
- **CITY** — GTA VI's launch day, glowing neon over the city

The program (`main.py`, Python 3.13, standard library only, no network)
copies the image the repo holds (`entry.jpg`) to `/output/entry.png`.
